SwasthPath is a comprehensive digital healthcare ecosystem built on three interconnected platforms designed to revolutionize healthcare access in India.

---

## 🏥 Three Pillars of SwasthPath

### 1. **SwasthPath** – The Pathway to Care
*Simplifying Healthcare Access*

- 📱 **Multilingual App & SMS Support**: Access healthcare in 22+ Indian languages
- 📋 **Queue Management System**: Virtual queuing reduces wait times
- 📄 **Digital Health Records**: Secure storage of patient history and reports
- 👥 **ASHA Worker Integration**: Seamless connection with community health workers
- 🚑 **Mobile Clinics & Outreach**: Healthcare brought to remote communities

### 2. **ArogyaNet** – The Intelligence Core
*AI-Powered Healthcare Intelligence*

- 🧠 **AI Case Classification**: Automatically classifies cases as General, Moderate, or Critical
- 📊 **Data Analytics**: Collects and analyzes health data for insights
- 🎯 **Smart Patient Routing**: Routes patients to appropriate care levels
- 🗺️ **Outbreak Prediction**: Early warning system for disease clusters
- 💡 **Actionable Insights**: Data-driven recommendations for resource planning

### 3. **JeevanSetu** – The Lifeline Network
*Emergency Response System*

- 🆘 **One-Tap SOS**: Instant ambulance dispatch with location sharing
- 💬 **SMS Emergency**: Works even on 2G networks
- 🚨 **AI Dispatch**: Intelligent routing to nearest available ambulance
- 📍 **Live Tracking**: Real-time ambulance location and ETA
- ⭐ **Accountability**: Feedback system and performance monitoring

## 📦 Installation

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Steps

1. **Clone the repository** (or navigate to the project folder):
   ```bash
   cd Swath_Parth
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to:
   ```
   http://localhost:3000
   ```

## 🛠️ Development

### Available Scripts

```bash

npm run dev

npm run build

# Start production server
npm start

# Lint code
npm run lint
```

### Customization

#### Colors
Edit `tailwind.config.ts` to customize the color scheme:
```typescript
colors: {
  primary: { /* your colors */ },
  secondary: { /* your colors */ },
}
```

#### Content
Update the content in each page file:
- `app/page.tsx` - Homepage
- `app/swasthpath/page.tsx` - SwasthPath
- `app/arogyanet/page.tsx` - ArogyaNet
- `app/jeevansetu/page.tsx` - JeevanSetu
